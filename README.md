# Eden Cost Control — Android

تطبيق أندرويد لبرنامج الكوست كنترول والمخازن (جزيرة عدن).

- شاشة دخول أصلية (Native) بتصميم احترافي + الدخول بالبصمة/الوجه (بيانات مشفّرة على الجهاز فقط).
- البرنامج يعمل داخل التطبيق بنفس حساب المستخدم وصلاحياته.
- تنزيل ملفات Excel، وحفظ/طباعة PDF، ورفع صور شكاوى الجودة من الكاميرا.
- شاشة انقطاع اتصال + السحب للتحديث + زر الرجوع.
- عنوان الخادم قابل للتغيير من أيقونة الإعدادات في شاشة الدخول (الافتراضي: https://cost.spirttravel.com/).

## البناء
كل `push` على `main` يبني APK تلقائياً عبر GitHub Actions، وينشره في **Releases**.

> ملف التوقيع `keystore/release.jks` موجود في المستودع — **حافظ على المستودع Private**.
> نفس المفتاح مطلوب لكل التحديثات (حتى يتحدث التطبيق فوق النسخة القديمة بدون حذف).
